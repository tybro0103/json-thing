# JSON Thing

Chrome plugin for humanized JSON. **Zero dependencies.** A few hundred lines of simple code.

## Why?

Cuz how else can you ever be sure those plugins aren't stealing your data?

## Features

- Expand/collapse objects & lists
- Annotations - array & object length, array indices
- Linkified URLs
- Selectable text in the UI is valid json
	- Includes properly formatted whitespace
	- Includes all the syntax characters in the correct places - brackets, commas, etc
	- Strings are backslash escaped - e.g.: newlines are displayed as `\n`
	- Annotations are not included
- Settings
	- Number of spaces for indentation
	- Show/hide array indices

## Install

- Go to `chrome://extensions`
- Turn on dev mode
- Click "Load unpacked"
